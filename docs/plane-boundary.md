# Public Control-Plane Boundary

`Shared-Space` is the public canonical protocol and specification plane for Project B.R.I.D.G.E.

## Owns

- public protocol specifications
- public-safe schemas and contracts
- generic state-machine definitions
- public-safe fixtures and conformance tests
- release manifests without sensitive bindings
- architecture documentation and version lineage

## Does not own

- sovereign authority
- execution authority
- private host bindings
- credentials or secret material
- durable interaction state
- exact evidence bytes
- host execution truth

## Governing distinctions

- `GITHUB_COMMIT != AUTHORITY`
- `GITHUB_MERGE != EXECUTION_AUTHORITY`
- `ACCEPTANCE != ACTIVATION`
- `EVIDENCE != AUTHORITY`
- `NO_PLANE_MAY_CREATE_AUTHORITY_FOR_ANOTHER_PLANE`
